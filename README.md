# Lineage II: Reborn

Браузерная MMORPG в духе **Lineage 2** — **мультиплеер работает на GitHub Pages** без сервера.

## Играть онлайн

**https://bfrees23.github.io/sam_test_cur/**

## Мультиплеер (P2P, только GitHub)

Мультиплеер работает через **WebRTC (PeerJS)** — напрямую между браузерами, без Node.js сервера.

### Как играть вместе

1. Откройте игру на GitHub Pages
2. Нажмите **🌐 Мультиплеер**
3. **Хост:** «Создать комнату» → создайте персонажа → получите код комнаты (6 символов)
4. **Друг:** «Войти в комнату» → введите код → создайте персонажа
5. Вы видите друг друга на одной карте!

### Ссылка-приглашение

После создания комнаты отправьте другу ссылку вида:
```
https://bfrees23.github.io/sam_test_cur/?room=ABC123
```

Код комнаты подставится автоматически.

## Локальный запуск (опционально)

```bash
npm start
# http://localhost:3000 — для сохранений в saves/
```

## Особенности

- P2P мультиплеер на GitHub Pages
- 6 классов, 5 рас, 5 зон
- Pixel art спрайты, parallax, декорации
- Чат (Enter), список игроков онлайн

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD | Движение |
| Tab | Цель |
| Enter | Чат |
| 1-3 | Скиллы |
| Space | Атака |

## Структура

```
├── js/network.js      # P2P мультиплеер (WebRTC)
├── js/world-art.js    # HD графика мира
├── js/pixel-data.js   # Pixel art спрайты
├── js/game.js         # Игровой движок
├── data/*.json        # Контент игры
└── index.html         # GitHub Pages entry
```
