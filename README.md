# Lineage II: Reborn

Браузерная MMORPG в духе **Lineage 2** — работает на **GitHub Pages** без сервера.

## Играть онлайн

После деплоя игра доступна по адресу:

**https://bfrees23.github.io/sam_test_cur/**

### Включить GitHub Pages

1. Репозиторий → **Settings** → **Pages**
2. **Build and deployment** → Source: **GitHub Actions**
3. Смержить PR в `main` — workflow автоматически задеплоит игру

## Локальный запуск (опционально)

```bash
# Простой статический сервер
npx serve .

# Или Node.js сервер с сохранениями в saves/
npm start
# http://localhost:3000
```

## Особенности

- **6 классов**: Воин, Гладиатор, Мистик, Клирик, Разбойник, Лучник
- **5 рас**: Человек, Эльф, Тёмный Эльф, Орк, Гном
- **5 зон**: Talking Island → Gludio Ruins → Orc Barracks → Windy Plains → Dragon Valley
- **18 скиллов**, экипировка Grade D/C/B, магазины NPC

## Сохранения

| Режим | Где хранятся |
|-------|--------------|
| GitHub Pages | `localStorage` браузера |
| `npm start` (локально) | `saves/*.json` в репозитории |

На GitHub Pages сохранения привязаны к браузеру и устройству.

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD | Движение |
| Tab | Смена цели |
| 1-3 | Скиллы |
| Space | Атака |
| E | NPC |
| I | Инвентарь |
| F5 | Сохранить |

## Структура

```
├── index.html          # Точка входа (GitHub Pages)
├── css/                # Стили
├── js/game.js          # Игровой движок
├── data/*.json         # Контент игры
├── saves/              # Сохранения (только локальный сервер)
├── .nojekyll           # Отключает Jekyll на GitHub Pages
└── .github/workflows/  # Автодеплой на Pages
```

## Редактирование контента

Все данные — JSON в `data/`. Добавьте монстра или предмет, запушьте в `main` — после деплоя изменения появятся на сайте.

## Требования

- Для локальной разработки: Node.js 18+ (опционально)
