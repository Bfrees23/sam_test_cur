# Lineage II: Reborn

Браузерная MMORPG в духе **Lineage 2** с **мультиплеером** и HD-графикой.

## Быстрый старт (мультиплеер)

```bash
npm install
npm start
# Откройте http://localhost:3000 в нескольких вкладках/браузерах
```

## GitHub Pages (solo)

**https://bfrees23.github.io/sam_test_cur/** — одиночная игра без мультиплеера.

Мультиплеер требует Node.js сервер (`npm start`) или деплой сервера на Render/Railway/Fly.io.

## Мультиплеер

- WebSocket синхронизация (`/ws`)
- Видны другие игроки в той же зоне
- Чат (Enter → ввод сообщения)
- Список игроков онлайн слева
- Синхронизация скиллов (визуальные эффекты)

Откройте игру в **двух вкладках** с разными персонажами — вы увидите друг друга на Talking Island.

## Графика

- Pixel art спрайты с обводкой и анимацией
- Parallax небо и горы
- Декорации: деревья, руины, кристаллы, факелы
- Ambient-частицы: светлячки, пыль, embers
- Атмосфера уникальна для каждой зоны

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD | Движение |
| Tab | Смена цели |
| 1-3 | Скиллы |
| Space | Атака |
| Enter | Чат |
| E | NPC |
| I | Инвентарь |
| F5 | Сохранить |

## Структура

```
├── server/multiplayer.js  # WebSocket сервер
├── js/network.js          # Клиент мультиплеера
├── js/world-art.js        # HD мир (parallax, декорации)
├── js/pixel-data.js       # Pixel art спрайты
├── js/sprites.js          # Рендерер
├── js/game.js             # Игровой движок
├── data/*.json            # Контент
└── server.js              # HTTP + WS сервер
```

## Деплой мультиплеера

1. Задеплойте репозиторий на Render/Railway (Node.js, `npm start`)
2. Игра автоматически подключится к WebSocket на том же домене
3. GitHub Pages остаётся для solo-режима
