# Lineage II: Reborn

Браузерная MMORPG в духе **Lineage 2** — все игровые данные и сохранения хранятся прямо в репозитории.

![Lineage II Reborn](https://img.shields.io/badge/Lineage-II-Reborn-gold)

## Быстрый старт

```bash
npm start
# Откройте http://localhost:3000
```

## Особенности

- **6 классов**: Воин, Гладиатор, Мистик, Клирик, Разбойник, Лучник
- **5 рас**: Человек, Эльф, Тёмный Эльф, Орк, Гном
- **5 зон**: Talking Island → Gludio Ruins → Orc Barracks → Windy Plains → Dragon Valley
- **12+ типов монстров**, включая боссов
- **18 скиллов** с кулдаунами, баффами и DoT-эффектами
- **Система экипировки** (Grade D/C/B), инвентарь, магазины NPC
- **Сохранения в репозитории** — файлы JSON в папке `saves/`

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD | Движение |
| Клик | Движение / выбор цели |
| Tab | Смена цели |
| 1-3 | Скиллы |
| Space | Базовая атака |
| E | Взаимодействие с NPC |
| I | Инвентарь |
| C | Характеристики |
| F5 | Сохранить |
| Esc | Меню |

## Структура репозитория

```
├── data/                  # Игровые данные (JSON)
│   ├── classes.json       # Расы и классы
│   ├── skills.json        # Скиллы
│   ├── items.json         # Предметы и экипировка
│   ├── monsters.json      # Монстры
│   └── zones.json         # Зоны, NPC, порталы
├── saves/                 # Сохранения персонажей (JSON)
├── public/                # Клиент (HTML, CSS, JS)
│   ├── index.html
│   ├── css/style.css
│   └── js/game.js
├── server.js              # Node.js сервер + API
└── package.json
```

## API

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/data` | Все игровые данные |
| GET | `/api/saves` | Список сохранений |
| GET | `/api/saves/:id` | Загрузить персонажа |
| POST | `/api/saves` | Сохранить персонажа |
| DELETE | `/api/saves/:id` | Удалить сохранение |

## Редактирование контента

Все игровые данные — обычные JSON-файлы в `data/`. Добавьте монстра, предмет или зону, перезапустите сервер — изменения сразу в игре.

### Пример: добавить монстра

```json
{
  "id": "dragon",
  "name": "Дракон",
  "level": 60,
  "hp": 8000,
  "patk": 100,
  "exp": 3000,
  "adena": { "min": 2000, "max": 5000 },
  "zone": "dragon_valley",
  "boss": true
}
```

Добавьте запись в `data/monsters.json` и ID монстра в массив `monsters` нужной зоны в `data/zones.json`.
