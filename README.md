# Lineage II: Reborn

Браузерная MMORPG в духе **Lineage 2** — **мультиплеер работает на GitHub Pages** без сервера.

## Играть онлайн

**https://bfrees23.github.io/sam_test_cur/**

## Общий онлайн-мир (P2P)

Мультиплеер работает через **WebRTC (PeerJS)** — без Node.js сервера, прямо на GitHub Pages.

### Как играть вместе

1. Откройте игру: **https://bfrees23.github.io/sam_test_cur/**
2. Нажмите **Новая Игра** или **Загрузить**
3. Подключение к общему миру происходит **автоматически** — комнаты и коды не нужны
4. Все игроки в одной зоне видят друг друга на карте и в чате

Первый подключившийся игрок становится хостом мира; если хост выходит, другой игрок автоматически подхватывает роль.

## Локальный запуск (опционально)

```bash
npm start
# http://localhost:3000 — для сохранений в saves/
```

## Особенности

- Общий онлайн-мир на GitHub Pages (без комнат)
- 6 классов, 5 рас, 5 зон
- Pixel art спрайты, parallax, декорации
- Чат (Enter), список игроков онлайн

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD | Движение |
| Tab | Цель |
| Enter | Чат |
| 1-3 | Скиллы |
| Space | Атака |

## Структура

```
├── js/network.js      # P2P мультиплеер (WebRTC)
├── js/world-art.js    # HD графика мира
├── js/pixel-data.js   # Pixel art спрайты
├── js/game.js         # Игровой движок
├── data/*.json        # Контент игры
└── index.html         # GitHub Pages entry
```
